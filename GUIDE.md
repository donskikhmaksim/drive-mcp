# Руководство: помощник по файлам (Google Диск)

Простыми словами, без технических деталей. Это помощник, который работает с
вашими **файлами на Google Диске**: ищет и читает документы, создаёт папки и
раскладывает файлы, переименовывает, открывает доступ другим людям, распознаёт
текст в PDF и сканах. Вы пишете обычными словами, что нужно, — он делает.

> Важно: удаление (в корзину) и открытие доступа помощник показывает заранее —
> вы подтверждаете.

## Что можно попросить

| Вы говорите | Что делает помощник |
| --- | --- |
| «Найди на Диске презентацию про бюджет» | Ищет файлы по названию и содержимому, показывает список. |
| «Положи этот файл в папку „Отчёты“» | Перекладывает файл в нужную папку. |
| «Создай папку „Отчёты 2026“ и убери туда все счета» | Создаёт папку и переносит в неё файлы. |
| «Прочитай, что внутри этого документа» | Открывает файл и пересказывает содержимое. |
| «Что написано в этом отсканированном договоре?» | Распознаёт текст в PDF/скане и читает его вам. |
| «Переименуй этот файл в „Договор итог“» | Меняет название файла. |
| «Дай Ивану доступ на редактирование этой папки» | Открывает доступ нужному человеку. |
| «Кто вообще имеет доступ к этой папке?» | Показывает список людей с доступом. |
| «Сохрани этот текст как файл на Диске» | Создаёт новый файл с вашим содержимым. |
| «Убери этот файл в корзину» | Отправляет файл в Корзину (можно вернуть). |
| «Загрузи на Диск это видео с телефона» | Даёт ссылку, по которой телефон заливает файл сам. |
| «Скинь ссылку, чтобы скачать этот файл» | Даёт временную ссылку на скачивание. |

Можно комбинировать: «Найди все PDF со словом „счёт“, создай папку „Счета“ и
перенеси их туда».

### Большие файлы — отдельная история

Маленький файл (примерно до 1 МБ) помощник передаёт сам, прямо через переписку.
Видео, тяжёлый PDF, фото в высоком качестве так передать нельзя — вместо этого
он даёт **временную ссылку**, а ваш телефон или браузер грузит и скачивает файл
напрямую, мимо чата. Такие ссылки живут ограниченное время (загрузка — около
недели, скачивание — час по умолчанию) и открывают ровно один файл. Пересылать
их не стоит: пока ссылка жива, файл откроется у любого, кто её получил, —
никакого дополнительного входа не потребуется.

### Ищем и читаем файлы

| Инструмент | Что делает | Пример запроса |
| --- | --- | --- |
| `drive_search` | Ищет файлы и папки на Диске (по названию, типу, содержимому). | «Найди на Диске презентацию про бюджет» |
| `drive_get_metadata` | Показывает сведения о файле: имя, тип, размер, владелец, ссылка. | «Что это за файл и когда он изменён?» |
| `drive_download_file` | Открывает/скачивает содержимое файла (Google-документы выгружает в текст, таблицы — в CSV). | «Прочитай, что внутри этого документа» |
| `drive_get_download_url` | Для больших файлов: выдаёт временную ссылку, по которой телефон или браузер скачивает файл напрямую, минуя переписку. Ссылка живёт час и открывает ровно один файл — делиться ею не стоит. | «Скинь ссылку, чтобы скачать это видео на телефон» |
| `drive_extract_text` | Распознаёт текст в PDF, скане или фото (OCR). | «Что написано в этом отсканированном договоре?» |
| `drive_get_permissions` | Показывает, у кого есть доступ к файлу или папке. | «Кто имеет доступ к этой папке?» |
